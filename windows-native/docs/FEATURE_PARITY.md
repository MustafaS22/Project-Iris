# Feature parity checkpoint

Baseline: macOS Iris 2.1.12, build 247, plus working-copy audit fixes. The audit and Windows planning docs were used to map macOS source. The legacy Electron 1.0 workspace remains separate.

**Status:** Core checked = exercised on macOS with offline .NET fixtures. SDK checked = native C# compiled against Windows references with synthesized XAML field declarations, without the WinUI XAML compiler. Missing = no implementation in this checkpoint. Nothing here has been executed on a Windows runtime.

| Experience | macOS source | Native Windows status and difference |
|---|---|---|
| Chat, composer, history and export | AssistantWorkspace, ChatMentionComposer, ChatHistoryView | SDK checked. Native panes, cancellable text streaming, saved conversations and Markdown export. Markdown presentation, richer @mention picker and chat history search are missing. |
| OpenAI and local inference | CloudModelService, ModelService, AccountService, ProviderReadiness | Core checked. OpenAI developer API and OpenAI-compatible endpoint. ChatGPT OAuth, model discovery and embedded inference are missing. |
| Gemini | CloudModelService, GoogleConfiguration | Core checked. Gemini API-key streaming. Cloud account login is missing. |
| Memory and context | AssistantMemory, KnowledgeMemory, IrisKnowledgeMemory | Core checked for manual memory, relevance and explicit attachments. Automatic recall extraction, Scan Now, Apple/Google connections, knowledge RAG and periodic import are missing. |
| General model voice and tone | IrisPersonality, AssistantLanguage, ResponsePromptPolicy | System prompt matches request language. Persona presets and response style controls are missing. |
| Dictation and playback | ContextAndVoice, VoiceCaptureSession, StreamingSpeechPlayer | SDK checked. Windows speech UI, local voices and serialized playback. Fish voices, Gemini speech, VoiceBox, continuous streaming narration and multilingual speech controls are missing. |
| Text agents | IrisAgentStore, IrisAgents, AgentPolicy | Core checked for persisted interrupted state and cancellation primitives. SDK checked for two concurrent text jobs, results and Stop. Auto-delegation, specialist profiles, corner peek, multi-step execution and agent Computer Use are missing. |
| Computer Use | ComputerUseSession, NativeComputerUse, ComputerUsePolicy, IrisComputerCursor | SDK checked for known native app launch and foreground process observation. No generic UIA tree/control operations, mouse/keyboard injection, planner, action receipts, shared visual cursor or automatic workflows. |
| Screenshot and screen understanding | ScreenGuidance, ScreenDrawing, ScreenSolution, DiagramPresentation | SDK checked for Windows Graphics Capture picker, one frame and selected-image OCR. Capture timing, privacy consent, protected windows and large/mixed DPI targets need runtime verification. Model vision, drawing overlays, diagrams and screen tutoring are missing. |
| Inline Drafting | InlineDraftController, InlineDraftGesture, InlineDraftSelection | Missing. Need UIA selection/focus verification, safe review, atomic text insertion and custom shortcut behavior. |
| MCP | IrisMCP | Core checked for Streamable HTTP handshake, discovery and explicitly reviewed calls. SDK checked for manual UI. Stdio, OAuth, resources, prompts, persistent connections and model routing are missing. |
| Attachments | ComposerPasteboard, AttachmentContent, AttachmentTray | SDK checked for text and local OCR image pickers. Clipboard and drag/drop, source indexing, Office/PDF extraction and multimodal provider input are missing. |
| Images | ImageGenerationService | Core checked for Cloudflare request and JPEG envelope. SDK checked for preview, cancellation and file picker. OpenAI image generation, PNG normalization, saved library receipts and live service test are missing. |
| Documents and websites | ChatCreationFiles, DocumentWriter, CreationLibraryView | SDK checked for @document Markdown responses and exporting the conversation. Standalone PDF, website staging, generated files library, embedded preview and document edit history are missing. |
| Presence and avatar | IrisViews, NotchAppearance, IrisAvatar, FloatingIrisController | SDK checked for accent-aware eyes, idle blink, task-state eye size, top-edge capsule, hotkey and best-effort fullscreen suppression. A capsule outline indicates app launch verification. Diffuse glow, independent floating avatar, expression selection, collapsed inline chat and custom positions are missing. |
| Settings, shortcuts and accessibility | AssistantWorkspace, IrisAppearanceSettings, IrisShortcuts, AssistantSupportSettings | SDK checked for provider/color/capsule/reduce motion options, one global hotkey and native control labels. Custom binding, app icons, high contrast and Narrator walkthrough are missing or unverified. |
| File access and vault | IrisStorageAccess, AccountService, ImageGenerationService | SDK checked for DPAPI, scoped pickers and guarded writes. No persistent folder scopes or edit/overwrite tooling. Full user-account/profile lifecycle test pending. |
| Notifications, startup and background | IrisMenuPanel, Project_IRISApp, IrisLocalStorage | SDK checked for minimized user process and hotkey. Windows notifications, tray integration, startup opt-in and reliable sleep/wake recovery are missing. |
| Onboarding and help | WelcomeJourney, WelcomeCoachController, AppTestingView | Settings provides manual setup. Voice-first onboarding, replayable walkthrough and app tests UI are missing. |
| Live data, focus and notebooks | LiveDataService, IrisCore, NotebookSession, StudentNotebooksView | Missing. Add with exact provider/privacy and platform contracts. |
| Updates and distribution | IrisUpdates, Sparkle, DMG | Windows build script, assets and MSIX manifest present. Packages, signed upgrade/uninstall and App Installer updates await a Windows runner and authorized signing. |
