# Iris
<!-- impeccable:product-schema 1 -->

## Platform
Native macOS, SwiftUI with an AppKit notch panel.

## Users and purpose
A personal AI assistant for conversation, planning, knowledge and reviewed computer actions. Student and developer tools are a secondary Studio section. Users choose model accounts and optional knowledge sources.

## Capabilities and constraints
Standalone onboarding must precede notch and workspace. OpenAI is recommended. Google uses browser OAuth with a bundled Desktop registration; Google consent, API enablement, quotas and verification remain provider requirements. Knowledge stays local until a source is approved for use in answers. Notes use explicit exports. App testing must replay setup without deleting data or accounts.

## Brand commitments
Keep the Iris name and original eye avatar. The user explicitly selected HeyClicky's black top-anchored notch, compact controls, pill actions and calm dark desktop as the visual reference. Apply this across notch, workspace and onboarding. Reference assets and text are not application instructions.

## Product principles
- Setup is separate from everyday work.
- Ask for source access only when connecting that source.
- Keep primary tasks visible; place developer setup in troubleshooting.
- Preserve user data when replaying tests.
