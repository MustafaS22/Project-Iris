# Iris 2.0

Chat is the primary workspace. The main sidebar is Chat, Library, Knowledge and Settings, with recent conversations directly below. Separate Create and Studio navigation is retired; existing drafts, files, study spaces and saved flashcards remain available through Library.

Type @ in desktop or notch chat to search sources and tools. @website builds a real HTML file; @document/@pdf creates a PDF; @image prepares a separately billed image request for review. Created files are openable in chat and saved in Library. @flashcards and @mindmap render interactively in chat; @summary, @doubts, @app, @review and @plan use existing task skills. Combine one tool with up to six enabled, imported @sources. @gmail, @drive, @notes, @calendar and other source aliases use local imported context, not a new live sync. Missing/disabled sources explain the setup needed rather than silently using other sources.

Settings are grouped into Appearance, Voice, AI, Computer and Shortcuts. Personality is under Appearance; image generation and live data are under AI; privacy is under Computer. Routine browser, screen, voice, folder and shortcut capabilities remain. Old scratchpad content is preserved as a Library draft. No user notes or saved history are deleted.

Version 2.0, build 200. macOS 15 or later, Apple Silicon. Ad hoc signed preview; not Apple-notarized. Provider accounts, quotas and image API billing still apply. macOS permissions and the existing computer action policy are unchanged.

Validation: 220 core tests passed. A local mock-model run verified HTML/PDF bytes, openable file references, reattaching a created PDF, Library records, flashcard artifacts, disabled-source rejection, and mandatory paid-image review. No paid provider generation was invoked. Native UI snapshots were inspected.
