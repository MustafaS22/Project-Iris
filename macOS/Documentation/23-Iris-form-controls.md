# Iris form controls

The shared IrisTextFieldStyle replaces rounded-border form inputs across Settings, onboarding, Studio, Creation, source connections, chat history and live data. Native text and secure editing use a 44-point minimum surface, charcoal gradient, 12-point corners and accent focus edge. Chat composers keep their dedicated layout.

IrisPicker replaces form pickers throughout the app. It keeps native menu selection and bindings inside a consistent labelled Iris trigger. Folder, browser, voice, time, format and display selections show human-readable names. Compact tab fallbacks and the knowledge source menu follow the same visual direction. Onboarding name and interests fields now have persistent labels and comfortable multiline spacing.

Validation: native Debug build passed. The browser selector surface and its Default browser/Safari menu options were verified in the running app. A paused older Xcode instance was stopped to unblock inspection. The computer-use service then disconnected; onboarding's final visual/interaction check could not be completed. No model inference was used for this UI validation.
