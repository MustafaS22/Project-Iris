# Notch quick settings

The notch gear opens a Settings tab inside the expanded notch. It stays pinned while settings are in use. Home, Chat, and Capture return to their usual content. Escape returns to Home before collapsing the notch.

Quick settings include all eight accent choices, a hue slider for Custom, the six Iris personalities, listen-on-summon, and spoken replies to voice requests. Changes use the existing preference storage and apply immediately. The content scrolls within a display-bounded height. Personality choices use Iris's custom dropdown.

The footer shows AI connection readiness and an explicit Full settings link for provider setup, voices, permissions, and other detailed controls. The Home footer also opens quick settings.

Validation: macOS Debug build succeeded. No paid model or speech requests were made.
